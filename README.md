# Управление Telegram-каналом "Эффект Даннинга — Крюгера"

Проект для управления контентом Telegram-канала [@dunningkrugereffect](https://t.me/dunningkrugereffect) через Claude Code.

## Структура проекта

```
daning-kruger/
├── content/
│   ├── posts/          # Опубликованные посты (100 сообщений, ID 9-109)
│   ├── media/          # Медиа-файлы из канала
│   └── drafts/         # Черновики новых постов
├── .claude/
│   ├── commands/       # Slash-команды для агента
│   │   ├── create-post.md   # /project:create-post
│   │   └── sync-channel.md  # /project:sync-channel
│   └── settings.json  # MCP-серверы (Telegram)
└── README.md
```

## Возможности

### Создание постов

Используйте естественный язык с агентом:

```
"Напиши пост про новый релиз Python 3.13"
"Создай заметку о путешествии на мотоцикле"
```

Или вызовите slash-команду: `/project:create-post`

Агент автоматически:
1. Прочитает последние посты для контекста
2. Напишет черновик в стиле канала
3. Покажет для review
4. После подтверждения опубликует в канал
5. Сохранит локально в `content/posts/`

### Синхронизация канала

```
"Подтяни новые посты из канала"
"Синхронизируй канал"
```

Или: `/project:sync-channel`

Агент:
1. Определит последний сохранённый пост
2. Получит новые сообщения из канала
3. Скачает медиа (если есть)
4. Сохранит всё локально

## Стиль канала

Подробный анализ стиля, тона и тематик автоматически доступен агенту через `CLAUDE.md`.

**Основные характеристики:**
- Неформальный, от первого лица
- Честный, с юмором и самоиронией
- Технический контент + личный опыт
- Тематики: IT, менеджмент, когнитивная психология, мотоциклы, гаджеты

## Формат постов

Все посты сохраняются как Markdown-файлы с frontmatter:

```markdown
---
id: 108
date: 2025-09-24 05:34:43+00:00
channel: dunningkrugereffect
has_media: false
views: 180
---

Текст сообщения...
```

## Известные ограничения

- Скачивание медиа через MCP может требовать дополнительной настройки путей
- Некоторые старые сообщения могут иметь только медиа без текста

## Быстрый старт

1. Откройте проект: `cd daning-kruger && claude`
2. Правила и стиль загружаются автоматически из `CLAUDE.md`
3. Скажите агенту: "Покажи последние 5 постов"
4. Или: "Напиши пост про [тема]"

Агент знает контекст канала и будет работать в правильном стиле.
